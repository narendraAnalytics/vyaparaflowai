GUARDRAILS - RULES THAT KEEP THIS FROM BECOMING A DUMMY PROJECT
================================================================================
[ ] Business logic NEVER lives in an n8n Code node. n8n orchestrates only.
[ ] Inventory and money change ONLY through a ledger row inside a transaction.
[ ] Every external call is idempotent, signed/authenticated, retried, timed out.
[ ] AI never takes an irreversible action alone - a deterministic rule gates it.
[ ] Every phase ends with a demo, a test, and a commit. No "I'll test later".
[ ] No mock data in the demo path. Real PDFs, real webhooks, real sandbox APIs.
[ ] If a phase drags past 1.5x its estimate, cut scope - do not cut Phase 8.
